## 1. 元策略：逐级释放与反馈循环

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `signal_escalation` |
| 名称 | 逐级释放与反馈循环 |
| 类型 | **meta_strategy**（元策略） |
| 来源 | 《魔鬼聊天术》Part 1 第4节 + Part 3 第9节 + Part 2 第1节 |
| 定位 | 位于 Emotion → Need 之后、具体 Strategy 之前，决定当前应释放什么强度的信号以及何时联系 |
| 目标 | 用渐进式的兴趣信号试探对方反应，根据四级好感信号解读反馈，以三三法则控制节奏，在情绪制高点出手升级关系 |

### 适用条件

- **适用描述**：全阶段适用，是追求过程的节奏控制框架
- **风险等级**：低

### 目标需求

被关注、安全感、认同感

### 核心理念

高手不是按计划表追求（今天必须联系一次、这周必须约出来），而是：

每次交互释放一个小的兴趣信号 → 观察反馈 → 正面继续升级 / 中性保持 / 负面退一步。

同时学会解读她的好感信号（四级），用三三法则控制联系频率。**菜鸟关注客观频率，高手关注情绪节奏**。

---

### 模块一：五级信号释放（你主动释放的兴趣信号）

| 等级 | 名称 | 强度 | 规则 |
|---|---|---|---|
| L1 | 赞美 | 最低 | 越具体越有性意味。笼统赞美 = 社交礼节，具体赞美 = 我在细致关注你 |
| L2 | 自我袒露（状态） | 低 | 说我做了什么。比单纯提问安全，展示自己但不暴露需求 |
| L3 | 自我袒露（状态+感受） | 中 | 说我做了什么 + 我觉得什么。开始引入情绪维度 |
| L4 | 自我袒露（状态+跟对方有联系的感受） | 高 | 说我做了什么 + 让我想起你曾经如何。最高级的袒露，隐形表达"你在我心里" |
| L5 | 提出要求 | 最高 | ① 干脆果断，不遮遮掩掩；② 符合当前关系层级，不可越级；③ 只提容易诉诸行动的要求，不提名分要求 |

---

### 模块二：四级好感信号（解读她的反馈）

> 来源：《魔鬼聊天术》Part 3 第9节·四级好感信号
>
> 原则：以其中好感程度最高的信号为准来判断关系阶段

#### L4 — 回应（最低）

- **状态**：不能升级的普通朋友关系
- **她的行为**：
  - 接你电话、回你短信
  - 内容平淡，态度礼貌
  - 至少搭理你，但不主动延伸
- **你的对策**：
  - ✅ 可以做：按她能接受的频率保持联系或邀约见面，耐心等待变化
  - ❌ 不可以做：不要口水式赞美、不要动不动送温暖送礼物、切忌表白升级
  - 🧠 心态：即使你什么都不做，也可能有其他因素让她的态度发生变化。你唯一能做的就是保持联系、细心观察、抓住机会，剩下的听天由命
- **信号强度**：最低——只是不拒绝你的存在

#### L3 — 倾诉

- **状态**：可先发展为好朋友，再升级
- **她的行为**：
  - 对你说话很多，内容具体
  - 感受丰富，话题敏感
  - 有安全感和信任感，觉得你是理解她的人
- **你的对策**：
  - ✅ 可以做：先牢固好朋友关系至少几个月，温水煮青蛙循序渐进
  - ❌ 不可以做：不要急于升级（女人会说"本来想跟你做朋友但你非要这样，那只能算了"）、不要表白太早（没交情就意味着对她来说没失去）
  - ⏰ 升级时机：等她对你产生相当的友谊依赖之后
- **信号强度**：低——信任你但不一定对你有男女兴趣

#### L2 — 关注

- **状态**：可从普通朋友向情侣升级，需继续了解
- **她的行为**：
  - 对你的话题积极响应
  - 对你的生活充满好奇
  - 关注你、对你有兴趣有好感
- **你的对策**：
  - ✅ 可以做：可以立即升级——语言表白或身体接触都行
  - 🎯 态度：轻松自信、诚恳豁达——"我知道你对我有好感，我也喜欢你，所以咱们再深入一步，但如果你反悔了我也能理解"
  - ⚠️ 注意：升级不意味着马上就会被接受，姑娘可能还有个考虑的过程
- **信号强度**：中高——对你有男女之间的兴趣

#### L1 — 依顺（最高）

- **状态**：可直接升级，一步成功
- **她的行为**：
  - 容易约出来
  - 愿意跟你在一起
  - 听从你的建议，接受你的要求
  - 两个字——**听话**
- **你的对策**：
  - ✅ 可以做：大胆提出要求，她会把满足你看成加深联系的美好体验
  - ⚠️ 注意：她有时会刻意表现出轻微抗拒——其实是想看你对她表现出更强烈的需求。把握好分寸就行（这种抗拒通常只是做做样子，但不是耍流氓的借口）
- **信号强度**：最高——已经非常喜欢你

### 模块三：即时反馈循环（根据她的即时反应决定信号升降）

| 反馈类型 | 信号特征 | 行动 |
|---|---|---|
| 正面反馈 | 对方接话有情绪、主动延伸话题、对你反向关注 | 释放下一级更强的信号 |
| 中性反馈 | 笑而不语、礼貌回应但无情绪波动 | 水滴石穿——持续当前强度，不退缩不急进，等待她的态度变化 |
| 负面反馈 | 冷淡、敷衍、不接话 | 退回上一级或换个时机再试，不纠缠 |

> ⚠️ 中性反馈时最容易犯两种极端：退缩（错过机会）或激进（吓跑对方）。

### 模块四：三三法则（初期联系频率控制）

> 来源：《魔鬼聊天术》Part 2 第1节
>
> 适用阶段：认识关系或普通朋友关系，互动还比较平淡的阶段

| 法则 | 名称 | 具体内容 |
|---|---|---|
| 法则一 | 每次联系三个回合 | 每次短信/微信联系只发三个回合，自己主动开始，自己主动结束。例外：如果对方突然热情了，也要灵活跟进——法则不是死规矩 |
| 法则二 | 每三至五天联系一次 | 不要太频繁。本质：间隔久到让她的友好本能恢复。原因：对于偶尔联系的朋友，人会自然表现出友好；对于没有特别吸引力却又频繁联系的交往对象，会自然回避甚至厌恶 |
| 法则三 | 每三次联系中安排一次模糊邀约 | 每联系三次，在第三次的第三个回合伺机进行一次模糊邀约。模糊邀约示例："哪天有空一起喝杯咖啡"而非"周六下午有空吗"——前者不会给对方压力 |

> 💡 **三三法则的本质**：给对方的友好本能留出恢复时间，同时在每次互动中主动控制始终（自己开始+自己结束），保持姿态。

---

### 模块五：首次邀约前置条件

满足以下条件**之一**即可邀约：

| 条件 | 说明 |
|---|---|
| 条件一：三三法则达标 | 虽然对方回复态度平淡，但总是有来有往，凑足三三法则后即可模糊邀约 |
| 条件二：单次互动深入 | 在单次互动中双方有十余回合以上的交流，且内容涉及生活细节、情绪感受 |

> ⚠️ 重要：即使不满足条件也可邀约，但满足条件后即使约不出来也不会让关系降级。"可以邀约" ≠ "约就必成"，只是不会退步。

---

### 禁忌模式

1. 制定追求计划表（周一联系一次、周三一次、周六约出来）→ 无视情绪节奏
2. 越级提要求（刚认识就邀约单独旅行）→ 关系降级
3. 得到正面反馈后犹豫不敢升级 → 错失窗口
4. 遭到负面反馈后继续强攻 → 死缠烂打
5. 在回应阶段（L4）就表白 → 冒进出局
6. 在倾诉阶段（L3）急于升级 → 她会说"本来想做朋友但你非要这样"
7. 联系太频繁让对方厌烦 → 忽视了三三法则
8. 该结束对话时没结束，拖成尬聊 → 忘记自己主动开始自己主动结束

### LLM 指令

你是一个逐级释放兴趣信号的追求者。当前对话中，根据对方的反馈状态决定下一步信号的强度。正面反馈→升级信号，中性反馈→保持当前强度，负面反馈→退回上一级。同时留意对方的四级好感信号（回应→倾诉→关注→依顺），判断你们处于哪个阶段、可以做什么、不可以做什么。在初期平淡互动中，使用三三法则控制联系频率（每次三个回合、每三五天联系一次、每三次联系做一次模糊邀约）。不要制定机械的频率计划，要关注对方的情绪节奏。

### 成功指标

每次释放信号后获得正面或中性反馈，逐级升温至关系升级。能准确识别她的四级好感信号，在对应的阶段做对应的事。

### 关联策略

`escalating_conflict`、`eighty_twenty_rule`、`validate_emotion_express_need`

## 2. 核心策略：扩大冲突

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `escalating_conflict` |
| 名称 | 扩大冲突 |
| 类型 | core_strategy |
| 来源 | 《魔鬼聊天术》Part 1 第4节 |
| 目标 | 将女方的调侃/否定信号转化为调情升温，制造暧昧氛围 |

### 适用条件

- **适用情绪**：开心、兴奋、期待、无聊
- **适用阶段**：暧昧、热恋、稳定
- **触发信号**：**女方向你发出带有调侃、质疑、否定色彩的信息——这是好感指标**

### 不适用条件

- **不适用情绪**：严重悲伤、愤怒、焦虑
- **不适用阶段**：初识、冷战
- **不触发条件**：女方尚未主动发起任何冲突信号时，男方不可主动发起

### 风险等级

中等

### 目标需求

被关注、情绪价值、分享欲

### 预期效果

| 维度 | 评分(1-3) |
|---|---|
| 吸引力 | 3 |
| 情绪参与 | 3 |
| 关系热度 | 3 |
| 话题延伸 | 2 |

### 核心机制

女方主动发起冲突 = 好感信号。

**不解释、不退缩、不岔开话题**，顺着冲突方向继续升级，把对话锁定在"你和她的关系"上。

解释 = 平息冲突 = 终结暧昧。

> 💡 冲突代表一种"更亲密的关系"，调侃往往比客气更有好感。客气说"你这人其实挺不错"= 发好人卡；假装生气说"你真讨厌"= 表达好感。

### 执行规则

1. **冲突必须由女方先发起**，男方不可主动发起冲突
2. **回应指向"你我关系"**，不可转向客观话题
3. **每次回应在上一轮基础上继续扩大**，形成回合制升级
4. **唯一例外**：巧合事件可从逻辑上自然导出冲突时，男方可主动（例如两人不约而同出现在同一个城市）

### 禁忌模式

| 错误做法 | 后果 |
|---|---|
| 解释自己 | 平息冲突，对话变无趣 |
| 傻笑/沉默 | 错失升温窗口 |
| 转向客观话题 | 脱离两人关系 |

### 示例

**示例一：搭讪后微信初聊**

- 女：看到漂亮女孩就要认识，你不会是个坏人吧？
- 男：我呀，遇到好人就是好人，遇到坏人就是坏人，这就看你是什么人了。
- **为什么对**：不解释人品，转而把"好坏"的判定抛回给她，锁定你我关系

**示例二：对方接招后继续扩大**

- 女：那你看我是什么人呢？
- 男：你一看就是大好人，唉，我太肤浅了，就会以貌取人。
- **为什么对**：冲突对方（好人）+ 冲突自己（肤浅），双重扩大

**示例三：女孩顺口释放情绪（泛泛抱怨也可抓取）**

- 女：唉，有的人命真好。
- 男：好人才有好报嘛，我掐指一算，小×童鞋本月再做一件善事就能晋级好人了。
- **为什么对**："有的人命真好"虽然是泛泛抱怨，但恰好构成冲突信号，抓住即扩大

### LLM 指令

对方的话语中包含对你的调侃、质疑或轻度否定。不要解释自己，不要转向客观话题。顺着她的冲突方向，把话题锁定在"你和她的关系"上继续调侃。你可以同时冲突她、也冲突自己。每次回应都应该比上一轮更进一步。

### 成功指标

女方继续接招调侃，对话回合数增加，关系温度上升。

### 关联策略

`devils_fun_rule`

## 3. 核心策略：认可情绪 + 表达需求

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `validate_emotion_express_need` |
| 名称 | 认可情绪 + 表达需求 |
| 类型 | core_strategy |
| 来源 | 《魔鬼聊天术》Part 2 第1节 |
| 目标 | 当对方向你表达犹豫、拒绝或不确定时，先认可对方的情绪以拉近距离，再表达自己的需求以争取机会，避免进入对立辩论 |

### 适用条件

- **适用情绪**：犹豫、不确定、轻微抗拒、羞涩、紧张
- **适用阶段**：初识、暧昧
- **触发信号**：
  - 对方对你提出的邀约/要求表达顾虑
  - "我都不认识你"、"太突然了"、"感觉怪怪的"、"这样不太好吧"
  - 对方用委婉方式表达犹豫而非直接拒绝

### 不适用条件

- **不适用情绪**：愤怒、冷漠
- **不适用信号**：
  - 对方已明确拒绝两次以上
  - 对方态度严肃且冷漠（非犹豫而是决心已定）

### 风险等级

低

### 目标需求

被理解、安全感、被尊重

### 预期效果

| 维度 | 评分(1-3) |
|---|---|
| 冲突减少 | 3 |
| 信任建立 | 2 |
| 对话延伸 | 2 |

### 核心机制

男方直接讲道理或施压 → 双方进入对立 → 关系疏远。

**认可情绪（上推）+ 表达需求（下切）** → 拉近距离后表达 → 女方感到被理解，更可能重新考虑。

**只坚持一遍即可**，继续拒绝就接受。

### 操作公式

| 步骤 | 名称 | 方向 | 目的 | 模式 |
|---|---|---|---|---|
| 第一步 | 认可情绪 | **上推** | 泛化为人类共有的泛泛之情，降低她的压力，拉近心理距离 | "我也知道{她的感受}确实会让人{泛化感受}" |
| 第二步 | 表达需求 | **下切** | 具体到此刻唯一的小请求，下切越具体安全感越高 | "但是我真的很想{具体行动}" |

> ⚠️ 关键细节："见面"比"吃饭"上推。选最下切的做需求表达——"吃饭"比"见面"更具体，安全感更高。反例："我也知道跟不熟的人吃饭挺别扭的，但是我还是挺想跟你见面"——语感生硬很多。

### 执行规则

1. **先认可情绪，再表达需求**——顺序不可颠倒
2. 认可时不要评价对方（"你想太多了"），只需反映感受
3. **只坚持一遍**。对方继续拒绝就接受，不纠缠
4. **表达需求要简洁**。形式上的复杂 = 感受上的沉重 = 情感过度
5. 不要讲道理论证"你应该见我"——男女之事本来就没有对错

### 禁忌模式

| 错误做法 | 后果 |
|---|---|
| 跳过认可情绪直接表达需求 | 对方感到被忽视 |
| 认可时变成讲道理（"我知道你的顾虑但是……"） | "但是"破坏了认可 |
| 需求表达情感过度（"临走之前"像"临死之前"一样沉重） | 吓跑对方 |
| 对方拒绝后继续追加理由 | 死缠烂打 |
| 反例："我马上就要离开了所以想临走之前能见一面" | 情感过度 + 表达太沉重 |

### 示例

**示例一：邀约被犹豫拒绝**

- 女：可是我都不认识你。
- 男：我也知道跟不熟的人见面挺别扭的，但是我还是挺想跟你吃饭。
- **为什么对**：认可（跟不熟的人见面挺别扭的）+ 需求（挺想跟你吃饭）。"吃饭"比"见面"下切，安全感更高

**示例二：搭讪后对方惊讶**

- 女：你吓了我一跳。
- 男：我也知道会这样，但实在来不及想其他办法了，因为我真的很想认识你。

**示例三：对方犹豫给联系方式**

- 女：我不太习惯给陌生人留电话。
- 男：其实我也不太习惯这样，但我真的很想认识你。

**示例四：对方感觉别扭**

- 女：这感觉挺别扭的。
- 男：我知道这样有些别扭，但我真的很想认识你。

**示例五：对方说有男朋友**

- 女：我有男朋友了。
- 男：我也想到你可能有男朋友了，但我真的很想认识你。
- **为什么对**：认可（想到你可能有）+ 需求（还是想认识）。只坚持一遍，对方再说"不"就退

### LLM 指令

对方表达了犹豫或抗拒。不要讲道理，不要论证"你应该同意"。第一步：用上推的方式认可她的情绪——把它说成是人类共有的正常反应。第二步：用下切的方式表达你的需求——具体到此刻唯一的小愿望。只表达一遍，不追加理由。如果对方继续拒绝，接受并礼貌退场。

### 成功指标

对方态度从抗拒转为愿意继续交流（如"你先自我介绍一下"），而非直接拒绝。

## 4. 核心策略：幽默化解越级请求

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `humorous_deflection` |
| 名称 | 幽默化解越级请求 |
| 类型 | core_strategy |
| 来源 | 《魔鬼聊天术》Part 2 第4节 |
| 目标 | 当对方用比喻或玩笑包装越级请求时，否定形式层面，用更夸张的方式在比喻内部回应，既不伤关系又不被占便宜 |

### 适用条件

- **描述**：对方用比喻、玩笑或轻松语气包装了一个超出当前关系的请求
- **触发信号**：
  - "你给报销吗？"（实际是让你出钱，但用了"报销"这个比喻）
  - "手机要欠费了，帮忙充200，见面还你"
  - "你请客吗？"（半开玩笑问）
  - 任何用玩笑语气提出的金钱/物质/时间越级请求
- **适用阶段**：初识、暧昧
- **关键指标**：请求使用了一个比喻包装（报销/充话费等），形式和实质分离——这是操作空间

### 不适用条件

- 对方赤裸裸直接索要且无玩笑语气
- 已确认对方是专门坑钱的——直接拉黑，不需要策略
- 情侣关系中的正常消费讨论

### 风险等级

中等

### 目标需求

被尊重、娱乐

### 预期效果

| 维度 | 评分(1-3) |
|---|---|
| 关系保护 | 3 |
| 边界设定 | 3 |
| 幽默感 | 2 |

### 核心机制

对方的请求有两层：**形式层**（比喻包装，如"报销"）和**实质层**（真实要求，如"出钱"）。

1. 先否定形式层（打破包装）
2. 再根据自己的意愿用更夸张的方式回应在实质层

**之所以有效**：保持了玩笑的框架 → 没有翻脸 → 不伤关系；用夸张拒绝 → 没有斤斤计较 → 对方无话可说。

### 操作公式

#### 第一步：否定形式层

- **目的**：拒绝她的比喻包装，但有幽默感，不严肃
- **模式**："别{对方的比喻动词}了，{转移理由}"

#### 第二步：意愿判断

**分支A：愿意接受实质**

- **模式**：否定形式 + 换个比喻接受实质
- **示例**："别报销了，现在正反腐呢，算我做个风投吧"
- **要点**：把"报销"（公对公）换成"风投"（有眼光），既出了钱又有姿态

**分支B：不愿意接受实质**

- **模式**：否定形式 + 夸张索取来平衡（你也要付出一样夸张的东西）
- **示例**："报销什么呀，嫁给我直接给你办张月票！"
- **要点**：不仅付出要夸张，**索取更要夸张**——"嫁给我"而非"做我女朋友"。夸张了才显得没斤斤计较，而对方肯定不会答应 → 没有成交可能 → 不伤关系

### 变体：无比喻包装的越级请求

当对方没有比喻包装，直接提越级要求时（赤裸裸的实质层，无形式层）：

- **方法**：不否定她的假设，顺着她继续夸张关系，然后根据夸大后的关系提出新要求
- **示例**：
  - 输入："手机要欠费了，帮忙充200元，见面还给你"
  - 回应："亲爱的，你这样让人太不放心了，现在到处是骗子，所以你还是别用手机了"
  - **逻辑**：她的逻辑链是"我们是朋友 → 朋友该互相关心 → 所以你帮我"。回应不否定"我们是朋友"，而是顺着夸大为"亲爱的"→ 根据夸大后的关系提出新要求"别用手机了（我关心你）"

### 执行规则

1. **先否定形式层，再处理实质层**——顺序不可颠倒
2. **始终保持在玩笑框架内**，不要翻脸进入严肃模式
3. 不愿意时：**索取比付出更夸张**——这是关键
4. 不要直接拒绝实质（"我没钱""我不愿意"）——在比喻内部拒绝
5. **心态先行**：先假设对方"脑袋进水"而非"居心叵测"，心态好才有好回复

### 禁忌模式

| 错误做法 | 后果 |
|---|---|
| 直接答应实质（"好的我报销"） | 跪舔，关系失衡 |
| 直接拒绝实质（"凭什么给你出钱"） | 翻脸，关系破裂 |
| 认真讲道理（"我们关系还没到这一步"） | 破坏了玩笑框架，尴尬 |
| 揣测对方动机（"你就是想坑我钱"） | 心态坏了，回复不可能有趣 |
| 拒绝时索取不够夸张（"你请我吃饭就行"） | 太小，变成真的讨价还价 |

### 示例

**示例一：愿意接受实质**

- 语境：聊到旅行，女方半开玩笑问费用
- 女：你给报销吗？
- 男：别报销了，现在正反腐呢，算我做个风投吧。
- **为什么对**：否定形式（报销）+ 换比喻接受实质（风投 = 我有眼光看好你）

**示例二：不愿意接受实质**

- 语境：同上
- 女：你给报销吗？
- 男：报销什么呀，嫁给我直接给你办张公园月票！
- **为什么对**：否定形式 + 夸张索取（嫁给我 + 月票），对方不会答应 → 安全拒绝

**示例三：小额轻松场景**

- 语境：线上聊到让对方来自己的城市
- 女：哼，让我去找你，你给报销门票吗？（5块钱门票）
- 男：门票算什么，往返路费加食宿全包，算我为拉动GDP做贡献。
- **为什么对**：否定形式（算什么）+ 换比喻放大接受实质（全包 + GDP调侃）

### LLM 指令

对方用玩笑或比喻包装了一个超出当前关系的要求。第一步：用幽默方式否定她的比喻包装——"别说什么报销了"、"什么充话费呀"。第二步：如果你愿意满足实质，换个更帅的比喻来答应；如果你不愿意，用比她更夸张的索取来回应——你的索取必须比她要求的东西更离谱，这样才显得没在斤斤计较。全程保持玩笑语气，不要进入严肃辩论模式。

### 成功指标

对方接受回应不尴尬，关系未降级，越级请求被化解。

### 关联策略

`devils_fun_rule`

## 5. 核心策略：大小二八原则

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `eighty_twenty_rule` |
| 名称 | 大小二八原则 |
| 类型 | core_strategy |
| 来源 | 《魔鬼聊天术》Part 3 第1节 |
| 目标 | 控制追求行为中"平等互动"与"不平等付出"的比例，避免跪舔，保持关系平衡 |

### 适用条件

- **描述**：追求阶段的所有互动行为，尤其是主动示好和帮助对方时
- **触发信号**：
  - 你想主动为她做点什么（送伞、接送、送礼物、帮忙等）
  - 她向你提出求助（借钱、帮忙、代劳等）
  - 你感觉"对她好"的冲动上来了
  - 每次约会和每次微信互动
- **适用阶段**：初识、暧昧
- **关键概念**：**请吃饭 = 平等互动**（男方虽有付出但女方不受益）；**对她好 = 不平等互动**（纯粹男方付出女方受益）

### 不适用条件

- 情侣关系中正常的互相关心
- 紧急情况（对方确实需要立即帮助）

### 风险等级

中等

### 目标需求

被尊重、安全感

### 预期效果

| 维度 | 评分(1-3) |
|---|---|
| 平衡维持 | 3 |
| 价值保持 | 3 |
| 防跪舔 | 3 |

### 核心机制

追女孩时，男人有原始冲动——对她好。但过度付出会造成**三重伤害**：

1. 失去平等相处和展示其他品质的机会
2. 筛选出只贪图好处的坏女孩
3. 降低你在她心中的价值（"他没见过我这条件的，我选他岂不亏了？"）

大二八控制平等 vs 不平等的比例，小二八控制满足求助 vs 主动发现需求的比例。

### 操作公式

#### 大二八（宏观行为比例）

| 类型 | 比例 | 定义 | 示例 |
|---|---|---|---|
| **请吃饭（平等互动）** | **80%** | 双方在平等基础上的相互了解。你虽然有付出（餐费等），但女方不因此受益——这是共同消费，不是单方面给予 | 约会吃饭、一起喝咖啡、共同参加活动 |
| **对她好（不平等互动）** | **20%** | 纯粹的男方付出、女方受益。可以展示你会照顾人的品质，但不能成为主旋律 | 接送下班、送礼物、主动帮忙 |

> ⚠️ 警告：20%~40% 无意义，40% 以上开始往跪舔之路发展。

#### 小二八（微观"对她好"的执行）

| 场景 | 比例 | 原因 |
|---|---|---|
| **她主动求助时** | 满足 **80%** | 80% 足以表明你是个好人，但 100% 就是老好人了。留 20% 巧妙拒绝保持姿态 |
| **你主动发现需求时** | 只满足 **20%** | 表明你具备会照顾人的品质就够了，多做无益 |

> 🔄 升级规则：除非你的主动示好之后，她对关系也有所投入，才可以追加主动付出。否则一厢情愿的主动付出就是跪舔。

### 执行规则

1. **大二八是底线**：平等互动必须占 80% 以上，不平等付出最多占 20%
2. 她主动求助才去帮——不要没事找事去发现需求
3. 满足 80% 的求助即可，留 20% 巧妙拒绝以保持姿态
4. 你主动发现的需求只满足 20%，不要做"体贴入微"的男人
5. 付出后观察她是否对关系有投入——有来有回才追加，单向付出立刻停
6. 区分"请吃饭"和"对她好"：一起消费 vs 单方面给予，前者平等，后者失衡

### 禁忌模式

| 错误做法 | 后果 |
|---|---|
| 一上来就各种对她好 | 跪舔，降低自身价值 |
| 她提的所有要求都满足 | 老好人，没有姿态 |
| 总在主动发现她的需求并满足 | 你以为在展示体贴，实际在跪舔 |
| 她没有任何投入时继续追加付出 | 单向关系，恶性循环 |
| 把"请吃饭"也当成"对她好" | 混淆概念，吃饭是平等互动不是恩惠 |
| 下雨就去接送、节日必送礼物、每天关心生活 | 都是过头的一厢情愿 |

### 示例

**示例一：普通朋友阶段的下雨天**

- ❌ 错误：我顺路去接你下班吧
- ✅ 正确：这雨下得真大，还好我今天带了伞
- **为什么**：普通朋友阶段不需要接送（属"对她好"），关注一下天气即可（属平等互动）

**示例二：女孩主动求助（满足 — 80% 情况）**

- 女：我电脑坏了，你会修吗？
- 男：会啊，你把具体情况发我看看，我教你排查
- **为什么**：她主动求助 → 满足她。但注意：远程教而不是上门修，避免变成工具人

**示例三：女孩主动求助（拒绝 — 20% 情况）**

- 女：周末能帮我去机场接个人吗？
- 男：这周末已经约了朋友，实在走不开
- **为什么**：虽然可以帮忙，但偶尔拒绝保持姿态——你不是随叫随到的

**示例四：你想主动"对她好"**

- 语境：注意到她朋友圈说最近加班多
- ❌ 错误：我每天给你送杯奶茶吧，加班别太辛苦了
- ✅ 正确：看到你朋友圈了，最近项目很忙啊？
- **为什么**：主动发现需求 → 20% 的份额很宝贵，只在关键时刻使用。闲聊时只需关注，不必急着出手帮忙

**示例五：第一次正式约会**

- ✅ 正确：正常请吃饭、请喝咖啡，吃完就结束，不额外送礼
- **为什么**：请吃饭是平等互动（大二八的 80%），约会后送礼物是不平等付出（已超出 20% 额度）

### LLM 指令

用户正处在追求阶段，他可能想为对方做点什么——接送、送礼物、主动帮忙。你需要判断这个行为属于"平等互动（请吃饭）"还是"不平等付出（对她好）"。如果不平等付出，检查：1) 当前这个行为在她的需求中占多少比例？2) 是她主动求助还是你主动发现？她主动求助可满足 80%，你主动发现的只满足 20%。如果比例已经超标，请建议用户克制冲动或改用平等互动的方式。记住：保持 80% 平等 + 20% 不对等的关系才能平衡，否则就是跪舔。

### 成功指标

互动保持平等基调，对方没有因过度付出而疏远，也没有因适当拒绝而离开。备胎感/老好人感被消除。

### 关联策略

`care_vs_attention`、`humorous_deflection`

## 6. 核心策略：关心vs关注

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `care_vs_attention` |
| 名称 | 关心vs关注 |
| 类型 | core_strategy |
| 来源 | 《魔鬼聊天术》Part 3 第6-7节 |
| 目标 | 根据关系阶段和对方的表达方式，准确判断该用"关心"（解决问题）还是"关注"（对状态表达兴趣），避免越级关心造成的压力和关系降级 |

### 适用条件

- **描述**：对方分享了一个状态（事件、情况、遭遇），你需要决定如何回应时
- **触发信号**：
  - 对方表达了一个客观状态（"下雨了""要搬家""加班""感冒了"等）
  - 你在考虑要不要提供帮助或给出建议
  - 你想表达温暖但不确定是否合适
- **适用阶段**：初识、暧昧、普通朋友
- **关键概念**：**关心 = 解决问题**（提醒/帮助/满足需求）；**关注 = 对状态表达兴趣**（作为旁观者回应）

### 不适用条件

- 情侣关系中——关系够了，关心和关注可自由切换
- 对方明确求助时——此时不是选择问题，而是你是否愿意帮
- 紧急危险情况——安全第一，不需要策略

### 风险等级

低

### 目标需求

被理解、安全感、被尊重

### 预期效果

| 维度 | 评分(1-3) |
|---|---|
| 回应恰当度 | 3 |
| 压力避免 | 3 |
| 连接建立 | 2 |

### 核心机制

关心的前提是**"你有资格关心她"**。资格来自两个条件：

1. 你们是好朋友及以上关系
2. 对方主动表达了感受

如果两个条件都不满足，你只能"关注"——做一个对她状态感兴趣的旁观者，而不是一个要解决问题的人。

> ⚠️ **越级关心的后果**：好女孩会有压力 → 减少接触；坏女孩会利用你的关心 → 变成工具人。

### 操作公式

#### 第一步：判断对方表达的类型

| 类型 | 定义 | 示例 | 信号含义 |
|---|---|---|---|
| **纯状态表达** | 只有客观事实，没有主观感受 | "要搬家""周末加班""下雨了" | 对方可能只是在陈述客观，不一定需要你的介入 |
| **状态+感受表达** | 客观事实附带了情绪和主观体验 | "要搬家，烦死了""加班加得快疯了""下雨了心情好差" | 对方在向你打开情绪窗口，可以跟进 |

#### 第二步：决策矩阵

| 关系阶段 | 表达类型 | 行动 | 示例 |
|---|---|---|---|
| 好朋友及以上 | 纯状态 | **可以关心** | "要不要我去帮你？" |
| 好朋友及以上 | 状态+感受 | **应该关心** | "搬家最累了，我来帮你吧" |
| 普通朋友 | 纯状态 | **只可关注，不可关心** | "昨天刚帮朋友搬家，换了新地方的人都特别开心" |
| 普通朋友 | 状态+感受 | **可以关心** | "搬家太折磨人了，需要帮手吗？" |

### 执行规则

1. **先看关系再看表达**——关系是门槛，表达是钥匙
2. 普通朋友 + 纯状态 → 关注即可。**宁可"不够暖"，不要"过于热"**
3. 对方加了感受词（烦、累、开心、难过）→ 关心窗口打开，可以跟进
4. 关注时也可以延伸话题，试探对方是否愿意进一步表达感受
5. 关心不是越贵越好——"要不要我去帮你"比"我帮你叫个搬家公司"更安全
6. 如果对方拒绝你的关心，退回关注即可，不要坚持"对你好"

### 禁忌模式

| 错误做法 | 后果 |
|---|---|
| 刚认识就无微不至关心 | 越级，给对方压力，显跪舔 |
| 对方只说了客观状态就忙着解决问题 | 你要的不是帮忙，是表现自己 |
| 普通朋友阶段什么忙都帮 | 变成工具人/备胎 |
| 对方明显有情绪表达你却只回应客观 | 太迟钝，浪费窗口 |
| 把关注变成讲道理（"搬家嘛，习惯就好"） | 不是关注，是爹味 |
| 反例：刚认识，对方说"今天加班"→ 你回"我来接你吧" | 越级。正确："最近你们公司挺忙的啊"——关注 |

### 示例

**示例一：普通朋友 + 纯状态**

- 女：周末要搬家。
- 男：昨天刚帮朋友搬家，换了新地方的人都特别开心。
- **为什么对**：关系不够 + 只有状态 → 关注。不急着帮忙，但延伸话题，如果她接着表达感受（"是呀，但我好烦"），就可以跟进关心

**示例二：普通朋友 + 状态+感受**

- 女：周末要搬家，烦死了。
- 男：搬家最容易让人崩溃了，需要帮手吗？
- **为什么对**：她表达了感受（烦死了）→ 给了你关心的窗口。即使普通朋友，此时关心也不算越级

**示例三：好朋友/暧昧 + 纯状态**

- 女：今天下雨了。
- 男：带伞了吗？要不我过去接你。
- **为什么对**：关系够了，即使对方只是陈述状态，也可以主动关心——你有资格

**示例四：感冒了——取决于关系**

- 女：感冒了。
- 普通朋友 → 关注：最近忽冷忽热的，好多人都中招了。
- 好朋友/暧昧 → 关心：发烧吗？家里有药没？要不要我给你送点？
- **为什么**：感冒是状态。普通朋友关注外部因素（天气），好朋友/暧昧可以关心她的具体情况

### LLM 指令

对方分享了一个状态。第一步：识别这是纯状态表达还是状态+感受表达（有没有"烦""累""开心"等情绪词）。第二步：判断你们的关系阶段——好朋友及以上可以关心，普通朋友要看有没有感受词。如果关系不到、又没有感受词，只做关注——像一个对她的生活感兴趣的朋友一样回应，而不是像一个急着帮忙的工具人。你可以用关注试探，如果她接着表达感受，再切换到关心。

### 成功指标

回应的关心程度与关系匹配，对方感到被理解而没有被越级的压力，不会因过度关心而减少接触。

### 关联策略

`eighty_twenty_rule`、`validate_emotion_express_need`

## 7. 表达增强器：魔趣法则

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `devils_fun_rule` |
| 名称 | 魔趣法则 |
| 类型 | **expression_booster**（表达增强器） |
| 来源 | 《魔鬼聊天术》Part 1 第4节 |
| 定位 | 位于 Strategy → Reply Draft 之后，对草稿进行表达增强后输出最终回复 |
| 目标 | 将任何策略输出的平淡表达转化为"有联系感的夸张行为"，提升情绪价值和话题延伸性 |

### 适用条件

- **描述**：几乎所有非严肃场景均可使用。特别在轻松、暧昧、日常闲聊场景效果最佳

### 不适用条件

- 正式道歉
- 严肃冲突处理
- 对方严重悲伤时需要纯共情而非趣味表达

### 风险等级

低

### 定义

**魔趣法则 = 具有联系感的夸张行为**

三个要素：

| 要素 | 含义 |
|---|---|
| **联系感** | 指向"你和我"的关系，保持互动性 |
| **行为** | 描述一个具体的、可感知的动作或场景，适合对方伸延话题 |
| **夸张** | 适度放大以制造趣味，让表达不像严肃诉求而是像开玩笑 |

### 为什么有效

联系感是追求中唯一可主观能动的因素。外貌、财富、性格都是稳定变量，短期内无法改变。但"你和她的联系感"可以通过语言即时营造——**在每一句话中植入"你我关系"，就是在每一句话中积累好感**。

> 来源理论：《魔鬼聊天术》Part 1 第8节："多数能够影响好感的因素都是比较稳定的变量……唯有一个因素是可以发挥主观能动性的，那就是你和她的联系感。"

### 安全法则

**用表达自己来代替评价对方**

### 平衡技巧

表达正面兴趣时，用另一半话语来平衡（负面效果/更重要的事/稀缺性/抬高或贬低自己），避免显得跪舔。使表达更像开玩笑，调动情绪效果更好。

五种平衡方式：

| 方式 | 示例 |
|---|---|
| 负面效果平衡 | "看着你的眼睛我都没心思工作了" |
| 更重要的事平衡 | "要不是加班，真想跟你一起逛个天昏地暗" |
| 稀缺性平衡 | "我来包吃包喝包玩，别人想要可都没有呢" |
| 抬高自己平衡 | "我的眼光就是好吧" |
| 贬低自己平衡 | "你当然是好人，唉，我就会以貌取人" |

### 示例（plain → boosted 对照）

**示例一：共情**

- 语境：女孩表达负面情绪
- 女：不开心。
- Plain：遇到什么事情了？
- **Boosted：啊，这是谁又欺负咱们了，让我去替你收拾收拾他！**

**示例二：共情**

- Plain：听起来你今天真的很累。
- **Boosted：这是谁又欺负咱们家小朋友了，让我去收拾他。**

**示例三：赞美**

- 语境：收到赞美时回应
- 女：你今天真漂亮。
- Plain：谢谢。
- **Boosted：对呀，不然怎么好意思站在你的身边。**

**示例四：关心**

- 语境：女朋友生病
- 女：感冒了，难受……
- Plain：多喝水，好好休息。
- **Boosted：宝贝你太不幸了，这么好的天气竟然在家生病，我这就过去给你做饭去。**

**示例五：开放式提问**

- 语境：对方表示没空
- 女：复习备考。
- Plain：哦，考什么呀？
- **Boosted：唉，可怜我们这些男同胞，想再偶遇你都没机会了。**

### 效果评估

| 维度 | 评分(1-3) |
|---|---|
| 话题延伸 | 3 |
| 情绪参与 | 2 |
| 趣味因子 | 3 |

### LLM 指令

将下面的回复草稿改写为魔趣法则风格。要求：1) 必须有联系感（指向"你我"关系）；2) 必须包含一个具体的行为或场景；3) 适度夸张让表达像开玩笑。优先表达自己的感受而非评价对方。如果草稿包含正面赞美或兴趣表达，用另一半话语来平衡，避免显得跪舔。

### 关联策略

`characterization`、`contrast_expression`、`emotion_labeling`
